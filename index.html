Retrain the Model

Add new sample data to data.xlsx and retrain XGBoost in one click

Retraining Workflow
01

Open the Data File

Open data.xlsx in Excel or Google Sheets.

data.xlsx → ML_Training_Data
02

Add New Rows

Append rows below existing data. Each row needs a Status of Approved or Rejected.

Vendors · Garment · Fit type · Fabric Type · Fabric Stretch Category
Ease Allowance Category · Block Pattern Name · Sealer · Technologist
Sample Round · TAT Days · RFT% (Computed Rolling) · Status
03

Save and Close the File

Excel locks files while open — close it before retraining to allow Python to read it.

04

Click "Retrain Model Now"

Reloads all data, re-engineers features, retrains XGBoost with 5-fold CV, saves new model.pkl.

05

Review Updated Metrics

New AUC-ROC, F1, and recall scores appear in the sidebar immediately after retraining.

  • Vendor analytics & KPI stats
